# Projeto: Tela de Login Simples

Este é um projeto de estudo desenvolvido de forma independente para praticar a criação de interfaces de autenticação. O foco foi aplicar conceitos de design visual e usabilidade utilizando apenas tecnologias fundamentais da web.

---

## 🚀 Sobre o Projeto

A aplicação consiste em uma interface de login minimalista, contendo campos para entrada de dados (e-mail/usuário e senha) e botões de ação. O projeto demonstra o domínio de alinhamento, estilização de formulários e feedback visual básico.

### 🛠️ Tecnologias Utilizadas
* **HTML5**: Estruturação dos campos de input, labels e botões.
* **CSS3**: Estilização visual, incluindo:
    * Centralização de elementos com Flexbox/Grid.
    * Estilização de bordas, cores e tipografia.
    * Efeitos de `hover` nos botões para melhor experiência do usuário.

---

## 🎨 Funcionalidades

* **Formulário de Acesso**: Campos validados nativamente pelo navegador.
* **Estética Moderna**: Uso de sombras (box-shadow) e bordas arredondadas para um visual contemporâneo.
